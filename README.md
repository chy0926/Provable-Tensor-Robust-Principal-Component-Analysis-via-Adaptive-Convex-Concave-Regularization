# AC2-TRPCA

MATLAB implementation of the method proposed in:

**Provable Tensor Robust Principal Component Analysis via Adaptive Convex-Concave Regularization**

## Requirements

- MATLAB R2023a

## Main Scripts

- `demo_Synthetic_Comparison.m`  
  Synthetic comparison experiments.

- `demo_real_data.m`  
  Hyperspectral image denoising and video background modeling experiments.

- `demo_ablation.m`  
  Ablation study.

- `Demo_Parameter_Sensitivity_Analysis.m`  
  Parameter sensitivity analysis.

## Data

The datasets used in the experiments are placed in the `data/` directory.

## Usage

Run the corresponding MATLAB scripts from the repository root directory.

All paths in the released scripts are configured as relative paths to facilitate reproducibility across different machines.
